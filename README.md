# Margem Clara (nome provisório)

Tudo fica em uma página só (`index.html`), com duas abas. Ferramenta para vendedores do Mercado Livre e da Shopee descobrirem o lucro real de cada venda.

- **Aba Calculadora**: lucro de uma venda e preço ideal para a margem desejada.
- **Aba Vendas importadas** (`index.html#vendas`): importa o relatório de vendas do Mercado Livre (Excel), recebe o custo de cada produto e mostra o lucro por venda e por produto.

O arquivo é lido no navegador; nenhum dado é enviado para servidor. Os custos digitados ficam salvos no próprio navegador.
